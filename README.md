FitLife Demo — Modern Fitness Studio Website
📖 Overview
FitLife Demo is a modern, responsive fitness studio website built with HTML and CSS.
It’s designed to help gym owners and trainers showcase their services, coaches, and pricing in a clean, professional layout.

✨ Features
Full‑screen hero section with motivational tagline

Sticky navigation bar for smooth scrolling

Service cards with INR pricing

Coach profiles with professional portraits

Testimonials and contact section

Mobile‑friendly design

WhatsApp integration for instant inquiries

🧩 Tech Stack
HTML5

CSS3 (Flexbox + Responsive Design)

Optional: Replace placeholder images with your own gym photos
